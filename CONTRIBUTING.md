# Contributing

Thanks for your interest in Camsur AI Studio! Ideas, bug reports and pull requests are welcome.

## Getting started

1. Fork the repository and clone your fork.
2. Follow the [Quick start](README.md#quick-start) to run the backend and the app.
3. Create a branch: `git checkout -b my-change`

## Before you open a pull request

- **Backend** (`camsur-backend`): run `pytest`. Follow the conventions in [ARCHITECTURE.md](camsur-backend/ARCHITECTURE.md).
- **App** (`camsur-flutter`): run `flutter analyze` and `flutter test`.
- Keep changes focused. One topic per pull request.
- Never include secrets, `.env` files or personal data.

## Pull requests

Explain **what** you changed and **why**, and add screenshots for UI changes.

## Reporting bugs

Open an issue with the steps to reproduce, what you expected, and what happened. For security problems, see [SECURITY.md](SECURITY.md) instead.
